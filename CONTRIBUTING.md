# Contributing to Digital Image Processing Labs

Thank you for your interest in contributing to this project! This document provides guidelines for contributing to the Digital Image Processing Labs repository.

## How to Contribute

### Reporting Issues
- Check if the issue already exists
- Provide a clear description of the problem
- Include steps to reproduce the issue
- Add relevant screenshots or error messages

### Suggesting Enhancements
- Clearly describe the enhancement and its benefits
- Explain why this enhancement would be useful
- Provide examples if possible

### Code Contributions

#### Getting Started
1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Digital-Image-Processing.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Set up your development environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

#### Coding Standards
- Follow PEP 8 style guidelines for Python code
- Use meaningful variable and function names
- Add comments for complex logic
- Include docstrings for functions and classes
- Keep functions focused and concise

#### Commit Messages
- Use clear and descriptive commit messages
- Start with a verb in present tense (e.g., "Add", "Fix", "Update")
- Keep the first line under 50 characters
- Add detailed description if necessary

Example:
```
Add Gaussian blur filter to lab06

- Implement Gaussian blur with configurable kernel size
- Add example usage in comments
- Update documentation
```

#### Pull Requests
1. Ensure your code follows the coding standards
2. Test your changes thoroughly
3. Update documentation if needed
4. Push your changes to your fork
5. Submit a pull request with a clear description

#### Pull Request Checklist
- [ ] Code follows project style guidelines
- [ ] Changes have been tested
- [ ] Documentation has been updated
- [ ] Commit messages are clear and descriptive
- [ ] No unnecessary files are included

## Code of Conduct

### Our Standards
- Be respectful and inclusive
- Accept constructive criticism
- Focus on what is best for the community
- Show empathy towards others

### Unacceptable Behavior
- Harassment or discriminatory language
- Trolling or insulting comments
- Personal or political attacks
- Publishing others' private information

## Questions?

If you have questions, feel free to:
- Open an issue for discussion
- Contact the repository maintainers

Thank you for contributing!
